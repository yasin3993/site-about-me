# Личный сайт — инструкция по запуску

## Что нужно установить

1. **Node.js** (версия 18 или новее) — скачать с https://nodejs.org
   (LTS-версия). Установщик уже включает **npm**, отдельно ставить не нужно.
2. Проверить установку в терминале:
   ```
   node -v
   npm -v
   ```
   Обе команды должны показать номер версии.
3. Любой текстовый редактор для правки — например VS Code.

## Структура папки

```
personal-site/
├── server.js          ← сервер на Express
├── package.json        ← список зависимостей
├── public/
│   ├── index.html       ← содержимое страницы
│   ├── style.css        ← оформление
│   └── script.js        ← пусто, задел на будущее
└── README.md
```

## Как запустить

1. Открыть терминал внутри папки `personal-site`.
2. Установить зависимости (один раз):
   ```
   npm install
   ```
3. Запустить сервер:
   ```
   npm start
   ```
4. Открыть в браузере http://localhost:3000

## Быстрый запуск в Chrome одним двойным кликом (Windows)

В папке лежит файл `start.bat`. После того как один раз выполнен `npm install`,
дальше сайт можно включать без терминала:

1. Дважды кликнуть на `start.bat`.
2. Откроется чёрное окно с сервером (не закрывать его, пока пользуешься сайтом)
   и через пару секунд автоматически откроется Chrome со страницей сайта.
3. Чтобы выключить сайт — просто закрыть то чёрное окно сервера.

Если Chrome не открылся автоматически (например, браузер установлен не как
`chrome`, а под другим именем в системе) — просто открой Chrome вручную
и зайди на http://localhost:3000.

## Что можно поменять под себя

- `public/index.html` — сам текст: имя, описание, блоки навыков, контакты
  (в конце файла — email, GitHub, LinkedIn, сейчас там placeholder-ссылки).
- `public/style.css` — цвета заданы переменными в самом начале файла
  (`:root { --bg: ...; --accent: ...; }`) — их удобно менять всей палитрой сразу.

## Если понадобится выложить сайт в интернет

Локально сайт работает только на твоём компьютере. Чтобы он был доступен
по ссылке всем, его нужно разместить на хостинге — например Render, Railway
или Vercel (для Node.js-приложений подходят первые два). Это отдельный шаг,
скажи, если нужно — распишу подробно.
